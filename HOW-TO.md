# HOW-TO — start a book

1. Create `books/<slug>/bible/`
2. Copy templates: P-HEAD, A-GUARDRAILS, D-ERA, B-CHARACTER, B-CHARACTER-ERA, E-SCENE, F-LEDGER, G-OPEN-QUESTIONS
3. Fill P-HEAD (time model + invention policy) before any prose
4. Lock one era deck
5. Lock one character invariant + that era slice
6. Snowflake 1–2 from locked facts only
7. Never draft until a scene ID exists and the user says DRAFT

If two sources disagree, log the collision. Do not average.
